download hermes from https://github.com/nousresearch/hermes-agent
set the API KEY in ~/.hermes .env file
set the model + provider in config.yaml.

example in config.yaml

model:
  default: meta-llama/llama-3.1-8b-instruct
  provider: openrouter
  base_url: openrouter.ai/api/v1

To run hermes in docker:
start docker desktop, whale apears

docker run -it -v ~/.hermes:/opt/data nousresearch/hermes-agent

docker ps , shows that its running
docker exec -u root -it <container_id_or_name> bash
